# Правила разметки eval_set_v1

## Метки
- `yes`: из текста явно следует, что платёж сделан в пользу или за счёт человека,
  который не плательщик и не получатель. Явное указание: предлог «за», «в пользу»,
  «в интересах», «за счёт» + ФИО, либо «выгодоприобретатель» + ФИО, либо «третье лицо».
- `no`: указания нет, либо оно отрицается («не привлекались»), либо слова-маркеры
  употреблены в другом смысле («физических лиц», «по счету», «поставка»).
  Если названный человек и есть плательщик или получатель, метка тоже `no`.
- `unclear`: разметчик не уверен, либо конкретное лицо не названо
  («за физическое лицо»). В метрики не входит.

## Особые группы
- `self_name` (13–15): ФИО плательщика или получателя указано в тексте. Метка `no`.
  Классификатор может ответить «третье лицо», снимает это сверка `isNotOperationParty`.
  Считаются отдельно, в precision/recall классификатора не входят.
- `near_template` / `near_example` (в `note`): конструкция близка к шаблонам генератора
  или к позитивным эталонам. Метрики по ним считаются отдельным разрезом.

## Состав
Всего 35 строк: 32 основных + 3 `self_name`.
Основные: `yes` = 17, `no` = 11, `unclear` = 4 (12,5%).
Одна строка = около 3 п.п. на 32 строках. На `no` (11) одна ошибка = около 9 п.п.
по доле верно отвергнутых. Accuracy как главную метрику не используем.
Ловушки (16–20): триггер из gate есть в 16, 17, 18, 20, нет в 19. Вне ловушек без триггера: 29.

## Разметка
Метки поставил один человек. Независимой разметки нет.
Соответствие меток правилам сверялось с помощью ИИ-ассистента.
Это не вторая разметка и не проверка истинности меток.

## Фиксируется до замеров
- Прогнозы по паттерну триггеров (не по результатам прогона): gate не пропустит
  строки 1, 5, 30, 32, 35 (единственный маркер «за» без триггер-слов; в 1 «счёт» с «ё»).
  Метрики считаются в двух разрезах: «прошло gate» и «не прошло».
- Варианты: A = текущий классификатор при порогах 0,5 и 0,75; B = гибрид
  (сильные маркеры + семантика).
- Метрики: precision, recall, F1 по `yes`; точное совпадение имени
  (регистр и е/ё игнорируются); разрезы по категориям и по near_template.
- Набор годится для сравнения вариантов и поиска слабых категорий,
  не для выбора порога с точностью до сотых.
- Изменение метки после замеров: отдельный коммит с причиной в сообщении.
