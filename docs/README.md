# Документация AVP ITeam

Вся документация проекта живёт здесь и правится вместе с кодом в PR.
Вики GitHub заморожена и только перенаправляет сюда.

Правила: новый документ = строка в этом индексе; доки, изменившиеся вместе
с фичей, едут в том же PR; устаревшее не удаляется, а получает статус `архив`.

## Статусы

- `актуально` — соответствует коду на main
- `ТЗ` — спецификация впереди кода (реализация в плане)
- `архив` — итоги за период, сохранены для истории и защиты
- `черновик` — в работе
